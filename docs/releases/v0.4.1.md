# v0.4.1

<span class="release-badge latest">Latest</span>

<div class="release-date-meta">July 9, 2026</div>

A small quality-of-life release focused on navigation polish and platform-specific window behavior.

## Link Preview

- **Hover URL preview** — hovering a link now shows a Chrome-style status bar at the bottom-left of the page with the destination URL; it's injected in the page's main world so it renders reliably, excluded from ad-blocker hiding rules, and sits flush against the bottom edge

## Shortcuts

- **Keyboard tab switching** — press `Alt` + `1` through `9` to jump directly to a tab by position

## Page Zoom

- **Pinch-to-zoom** — two-finger pinch gestures now zoom page content, driven from the page's Ctrl+wheel events so it works correctly on macOS trackpads

## Bug Fixes

- **New-tab page URL handling** — URLs typed on the new-tab page now navigate directly instead of being sent to the search engine
- **macOS fullscreen controls** — the traffic-light window controls are now available in fullscreen
- **Linux window behavior** — Nav0 now launches maximized with native window controls instead of borderless fullscreen, keeping the taskbar visible and fixing missing window decorations on Linux Mint

## Docs

- **README cleanup** — removed stale documentation references from the README
