# v0.5.0

<span class="release-badge latest">Latest</span>

<div class="release-date-meta">November 27, 2026</div>

A redesign release. The "paper and red" look from v0.3.0 is replaced by a neutral design system across the whole browser, and the same work closes a set of privacy, security and tab-lifecycle bugs found along the way.

## Redesign

- **New design system** — cool-grey window chrome, white pages with grey panels, and one blue accent for anything interactive or selected; red now appears only for danger: insecure connections, failures and the confirm button of a destructive action
- **Connected active tab** — the active tab and the toolbar share one surface with no line between them
- **One selection style** — the options menu, Command-K, Command-O, URL autocomplete, the Settings sidebar and filter chips all mark the selected row with a soft blue background and a blue icon, replacing the red anchor bar
- **Frosted menus and dialogs** — menus, popovers, palettes and dialogs share one frosted material, drawn solid when your system asks for reduced transparency; Command-K and Command-O are 98% opaque so their text stays readable over dark pages
- **Built-in pages** — New Tab, History, Bookmarks, Downloads, About, Settings, the error page, the certificate warning, dialogs and the screen-share picker are all redrawn; History, Bookmarks and Downloads now share one layout, with badges, durations and sizes lined up in fixed columns
- **Private windows** — a lavender tab strip and toolbar with a "Private" label replace the red "Private!" chip
- **Address field** — the site's registrable domain is emphasised; on a certificate error the field shows a red triangle and a struck-through `https`
- **Missing site icons** — every place that shows a site icon falls back to the same letter tile, where it used to show a blank slot, a globe or a window icon
- **Consistent formats and names** — one time and date format everywhere ("5:03 PM", "May 24"), macOS shortcut glyphs (⌘ ⌥ ⇧), and Keyboard Shortcuts uses the same command names and icons as the options menu
- **Accessibility** — focus rings appear only after keyboard use, never on a mouse click; the interface honours reduced motion, reduced transparency and increased contrast settings

## Keyboard & Focus

- **Options menu from the keyboard** — the ⋮ menu now takes focus: arrow keys move between rows, Right and Left open and close the History and Help submenus, Enter activates, Esc closes it
- **Find bar focus** — keystrokes go straight into the find field when the bar opens, including when you switch back to a tab that had it open
- **New window focus** — a new window, private or not, puts focus in the New Tab search field instead of on the tab strip's + button

## Privacy

- **No remote icon requests from built-in pages** — History, New Tab, Bookmarks, Command-K, Command-O and address-bar suggestions used to load stored remote favicon URLs, or guess `https://<site>/favicon.ico`, sending a request to every site listed; they now show only local copies from an on-device favicon cache, and their content security policy blocks remote images
- **Private-window favicons stay in memory** — favicons are fetched in the tab's own session, so they use its proxy and a private window's never touch disk; they previously went through the default on-disk session
- **Built-in pages kept out of History** — a window that opens on a URL no longer leaves a "New Tab · localhost" row behind
- **Private downloads on close** — closing the last private window now cancels that session's unfinished downloads and deletes their partial files instead of leaving them on disk

## Security

- **Escaped page data** — file names, page titles and favicon URLs are now escaped on the Downloads, History, Bookmarks and Settings pages, so a crafted name can't break out of the markup
- **Reader mode title** — the reader-mode header is built as plain text, so a page title can't run as markup
- **Certificate warning** — a later visit to the same URL can no longer skip the warning, and Proceed works only from the warning itself
- **Sub-resource certificate errors** — an image, script or iframe with a bad certificate is blocked, as in Chrome, instead of replacing the whole page with a warning about that resource
- **Favicon fetching** — cookies go only with favicons on the page's own origin, redirects to anything but http(s) are refused, and icons over 1 MB are dropped

## Ad Blocker

- **CAPTCHA challenges** — hCaptcha and reCAPTCHA challenge windows were hidden as soon as they opened, so the CAPTCHA could never be solved; hCaptcha, reCAPTCHA, Cloudflare Turnstile, Arkose/FunCaptcha and GeeTest are now exempt from blocking

## Bug Fixes

- **Downloads survive closing a window** — closing any window paused every download in the app; downloads now keep running until you quit
- **Pages that close themselves** — a page calling `window.close()` left a dead tab that couldn't be closed and could stop its window from closing; the tab now closes like any other and can be reopened
- **Closing tabs** — closing several tabs at once no longer leaves a blank page with no active tab, closing a background tab no longer dismisses the active tab's permission prompt, and closing a tab with the find bar open no longer leaves the bar stuck on the next one
- **Back and Forward** — skip history entries a page added without your input, as in Chrome, and stay in step with iframe navigations
- **Stuck loading spinner** — the tab spinner and Stop button clear after 60 seconds if a page never reports that it finished loading; the load itself keeps going
- **History summaries** — the Top Sites and By Category panels total the whole selected range instead of only the rows loaded so far
- **Tab strip** — tab titles can no longer be selected like page text, favicons can't be dragged out, and restored tabs show their icon before they load
- **macOS window** — Nav0 opens as a normal window zoomed to fill the screen instead of in its own fullscreen Space
- **Settings** — General shows the real downloads folder, Developer shows only your platform's DevTools shortcut, the sidebar stays put while the content scrolls, and Remove All in Site Permissions removes only the sites a search is showing
- **Link status bar** — on built-in pages it shows `nav0://` addresses instead of the app's internal file paths

## Upgrade Notes

- **Favicon migration** — on first launch a one-time database migration moves saved site icons into the new local cache; history and bookmark entries whose icon was a remote URL show a letter tile until you visit that site again
